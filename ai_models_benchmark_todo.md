# Возможные улучшения AI Models Benchmark

Текущая версия программы: `v0.9n`.

## Ближайшая версия

- Добавить расчётную стоимость запуска в отчёт: формула `input*pin + (output+reasoning)*pout + cache*pcache` проверена до цента, тарифы брать из `opencode models --verbose`; пометить значение как расчётное и решить поведение без доступных тарифов.

- Поддержать флаг `--variant` (`low`/`medium`/`high`...) в запуске OpenCode-модели: передавать как есть в `opencode run`, показывать вариант в выборе, отчёте и имени файла; без валидации имён (ошибку отдаёт сам OpenCode). Конфиг пользователя проверен 2026-09-20: скрытых умолчаний variant нет, прошлые прогоны шли на дефолтах моделей.
- Открытые вопросы по вариантам: полный список effort-вариантов есть в `opencode models --verbose` (снят 2026-09-20: у Muse `minimal`–`xhigh`, у Mimo/Kimi/Qwen вариантов нет вовсе, ключи бывают `reasoningEffort`/`effort`/`thinking`), но значение по умолчанию для каждой модели CLI не показывает; непонятно, надо ли хранить таблицу вариантов в бенчмарке и как обозначать прогон на дефолте в отчёте.

- Решить, нужны ли разные коды выхода для успеха, ошибок аргументов, ошибок провайдеров и исключений: сейчас программа всегда завершается с кодом 0, что мешает автоматизации; при изменении сохранить ожидание Enter и обновить тесты и документацию.

## Ollama: thinking и расширенный формат

- Расширить текущий запрос Ollama `/api/generate`, не подменяя его форматом OpenCode или LM Studio.
- Добавить настройку `think` для запуска моделей, поддерживающих размышления.
- Обрабатывать в потоковом ответе Ollama отдельные поля `thinking` и `response`: показывать их раздельно и сохранять раздельно в отчёте.
- Сохранять reasoning-метрики Ollama, если они присутствуют в итоговом ответе, и не подменять их нулём при отсутствии.
- Определить безопасное поведение для моделей без поддержки `think`: не отправлять параметр, отключать его или обрабатывать ошибку без потери результата.
- Решить, нужен ли переход с `/api/generate` на `/api/chat` для ролей сообщений, истории диалога и будущей поддержки инструментов; для текущего одного промпта достаточно расширить `/api/generate`.
- Добавить тесты потоковых ответов Ollama с thinking, обычным ответом, итоговой статистикой, пустыми полями и ошибкой неподдерживаемой функции.

## Отложенные замечания ревью (проверять при проблемах)

- При разъезжании колонок проверить вычисление ширины через `len()`: для европейских языков текущего подхода достаточно, а проблема может возникнуть с широкими восточноазиатскими, комбинируемыми и другими нестандартными Unicode-символами в интерфейсе или названиях моделей.
- При росте тестов объединить три хелпера изолированного прогона (`run_with_test_choice`, `run_isolated`, `run_scenario`) в один параметризованный.
