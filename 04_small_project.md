# Маленький проект: файловый журнал расходов

Создай небольшую законченную программу на Python 3 в одном файле.

Задача: консольный журнал расходов.

Требования:

1. Программа хранит данные в JSON-файле рядом со скриптом.
2. Пользователь может:
   - добавить расход;
   - посмотреть все расходы;
   - посмотреть общую сумму;
   - посмотреть сумму по категории;
   - удалить расход по его ID.
3. У каждого расхода должны быть:
   - ID;
   - дата;
   - категория;
   - описание;
   - сумма.
4. ID должен сохраняться корректно между запусками и не должен повторяться после удаления старых записей.
5. При первом запуске файл данных может отсутствовать - это нормальный случай.
6. Если JSON-файл повреждён, программа должна показать понятное сообщение и не перезаписывать повреждённый файл автоматически.
7. Никаких сторонних библиотек.
8. Всё должно быть в одном `.py` файле.
9. Не создавать классы и дополнительные архитектурные уровни без реальной необходимости.
10. Следовать KISS и YAGNI.
11. Не добавлять функциональность, которой нет в требованиях.
12. Не добавлять защитные проверки для состояний, которые невозможны согласно собственной логике программы.
13. Код должен быть понятным человеку, который знает Python на базовом уровне.
14. В начале ответа кратко объясни выбранную структуру программы и почему она достаточна.
15. Затем покажи полный код.
16. После кода перечисли:
    - какие реальные ошибки обрабатываются;
    - какие проверки ты сознательно не добавлял;
    - где в программе хранится состояние;
    - как обеспечивается уникальность ID.
17. В конце покажи короткий пример обычного пользовательского сценария работы программы.

Важно: не усложняй решение ради масштабируемости, тестируемости, паттернов проектирования или гипотетического будущего.
